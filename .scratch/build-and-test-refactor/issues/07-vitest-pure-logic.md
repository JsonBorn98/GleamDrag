# 07 - Vitest 迁移：纯逻辑测试全量离线化

**构建什么.** 把不依赖浏览器扩展 API 的纯逻辑测试全量迁入 Vitest（工具、日期、变量替换、本地化、解析器、菜单构建等），离线快速反馈；依赖 webextension-polyfill/DOM 的留在扩展内契约套件。断言风格保持外部行为导向。依据 ADR 0002 测试双栈。

**阻塞于.** 04

**状态.** ready-for-agent

- [ ] 全部纯逻辑测试在 Vitest 下通过，离线秒级可跑
- [ ] 依赖扩展运行时的测试留在扩展内套件未被迁移
- [ ] 断言风格保持外部行为导向，不测实现细节
- [ ] Vitest 纳入退出码契约（故意失败用例非零退出）
